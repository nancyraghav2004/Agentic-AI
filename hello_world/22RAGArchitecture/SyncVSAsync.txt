So we are going to do is, we will be having python fast api server, now user give some query that hey can you please 
resolve this query and give me ans, so there are 2 approach
1. user ask query --> Server -(code), 
so we can write code and let the user wait and block your whole server and return the response. (so when other users
are coming to that server, but server is blocked and busy in resolving first user's query.)

2. So rather than doing everything here (Server -(code)), we push the request into the queue, so that means we have got your request, please wait.
user ask query --> Server --> Queue --> seperate processor
so we will we having then seperate processor/consumer, this consumer going to pickup the task at a time and
will process it sand store the result in some kind of database, and when user ask, give it to user.
